# Caltek

A private calorie journal. Targets come from a Mifflin–St Jeor energy model. Meals are matched against a built-in food table, or entered by hand.

```bash
cd ~/Documents/calorie-tracker
npm install
npm run dev
```

Data stays in this browser under `localStorage` key `caltek.v1`. Privacy, terms, the health disclaimer, and third-party notices are in the app under Legal.
